# 0001. Record architecture decisions

Status: accepted

## Context

This project is built and maintained by one developer and has already sat untouched for two years.
The reasoning behind decisions is the first thing that gets lost.

## Decision

Record significant decisions as short numbered files in `docs/adr`, each with Status, Context,
Decision and Consequences. A decision is changed by adding a new record that supersedes the old
one, not by editing history.

## Consequences

A little overhead per decision, and a written trail for the future maintainer, who may be the
same person.
